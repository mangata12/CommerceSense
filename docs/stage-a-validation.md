# 阶段 A：数据传递与计算口径验收

日期：2026-10-08。基线：`8c864bf`。范围仅包含阶段 A；中文四入口、连续对话、规则检索阈值、完整周报和部署仍待后续阶段。

## 实现内容

- `commerce_session.py` 保存文件内容指纹、原始表、已应用映射、标准数据和质量报告。相同内容不重复读取；重新映射始终使用原始表。换文件或应用映射清理旧问答、工具结果、周期和报告状态。
- `commerce_data.py` 按文本读取 CSV/XLSX 编号；统一解析本地日期、Decimal 数量和单价，列出排除记录与原因。负数量和重复明细保留；整数最小货币单位汇总金额。币种需明确选择。
- `commerce_metrics.py` 统一使用相同校验逻辑；按商品编号优先聚合，支持名称回退及精确商品下钻。去重订单数包含冲销订单，客单价使用净销售额／周期去重订单数；客户字段缺失时返回无法统计。
- `app.py` 指标、Agent 和图表读取同一标准数据，待应用的新映射不用于分析。高级工具使用数据副本，数据处理预览不覆盖经营数据。
- `commerce_agent.py` 订单证据以结构化 JSON 返回明细，给出总条数及最多 100 条的实际返回数；商品筛选说明使用贡献表的精确标识。

## 验证方法

本次结果：22 项测试全部通过，Python 编译检查通过。测试不包含真实模型 API 或浏览器人工验收。

使用项目 `.venv` 运行：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m compileall -q app.py commerce_data.py commerce_session.py commerce_metrics.py commerce_agent.py tests
```

覆盖范围：

- 中文列名、UTF-8/GB18030 CSV 和 XLSX 文本编号前导零。
- 同名文件更换内容触发清理；相同内容不重读；从原始表重新映射且不复用未映射的旧标准列。
- 整数分、金额精度、部分冲销、重复明细、无效日期、时区日期、非有限数量、负单价、空订单号和空数据集。
- 日期结束日全天、空周期、缺客户字段、同名不同编号、名称回退、精确商品下钻，以及完整商品变化之和等于总变化。
- LangChain 业务工具直接调用，检查其使用映射后的数据和结构化订单证据。该项不代表真实模型调用或完整 Agent 编排验收。
- Streamlit AppTest 实际执行表单与页面重跑：选择币种、应用映射、修改日期、修改单价映射、再次应用映射，以及清除旧答案／报告。无密钥可查看经营指标。

人工可核对样本：9 月 1 日订单 `001` 为 3 × 0.10 = 0.30；9 月 2 日订单 `002` 为 1 × 0.20 = 0.20，订单 `003` 为 -1 × 0.10 = -0.10。两日净销售额 0.40 CNY，去重订单数 3；9 月 2 日净销售额 0.10，相对前一日变化 -0.20。同名“杯子”的 `01` 和 `02` 保持独立。

## 实测环境与限制

Python 3.12.14；Streamlit 1.64.0；Pandas 2.3.3；NumPy 2.5.3；LangChain 0.3.30；langchain-core 0.3.86；langchain-openai 0.3.35；scikit-learn 1.9.1；openpyxl 3.1.5。版本来自本次环境检查，固定直接依赖安排在阶段 D。

- 页面验证采用 AppTest，无常驻服务、真实浏览器手动检查或真实 DeepSeek API 调用；没有用模拟调用冒充真实 API 验收。
- 界面仍有英文标签、密钥提示和上游 `use_container_width` 弃用提示，留在阶段 B 的页面调整中处理。
- 只验收 CSV/XLSX；旧版 `.xls` 的可选解析依赖与格式未验收。
- Excel 原文件中已丢失的前导零无法恢复；读取第一张工作表。带时区日期需先转换为统一的本地时间；不推断时区、不换汇。
- 单价和金额必须精确到分；不足最小货币单位的明细会排除。页面和工具的金额展示转换为主货币单位，内部 `*_minor` 整数字段用于金额对账。
- 数据与映射仍在 Streamlit 当前会话内保存，不持久化、不支持多人共享。完整报告导出尚未实现。
