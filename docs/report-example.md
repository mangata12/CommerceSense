## 复现和查看

```powershell
.\.venv\Scripts\python.exe scripts/export_demo_report.py
```

输出位于 `outputs/demo_report/`，包含 `report.md`、四份 CSV、两张 PNG 和 `report.zip`；ZIP 内还含 `manifest.json`。整个过程不调用模型、不需要密钥。可直接打开 `report.md` 和相邻 `charts/` 下的图片，或解压 ZIP 查看完整报告。

脚本每次重新计算，生成时间和 ZIP 字节可能改变；核对时比较周期、币种、整数分、商品及证据，不比较报告包哈希。`outputs/` 已被 Git 忽略，不将生成报告或私有上传数据同步到仓库。
