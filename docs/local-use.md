# 本地使用指南

## 启动与停止

当前验证环境为 Windows、CPython 3.12.14。先安装 Python 3.12，在 PowerShell 进入项目目录：

```powershell
Set-Location C:\Users\zhuyiren\Desktop\zhuyiren\CommerceSense
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1 --server.port 8501 --browser.gatherUsageStats false
```

已有 `.venv` 时无需重新创建。打开 `http://127.0.0.1:8501`，保持启动终端运行；使用结束后在该终端按 Ctrl+C。命令只监听本机，不对公网开放。本轮没有部署到云服务器。

本地配置使用 `server.fileWatcherType="poll"` 和 `server.runOnSave=true`，检测代码内容变化后自动重跑。虚拟环境、原始／私有／处理后数据及输出目录不监控。已有旧服务必须先停止，再用上述命令启动，才能加载配置；重启后重新上传文件和填写会话密钥。正常保存代码引发的重跑会保留当前会话数据。正式部署时可使用 `--server.runOnSave false` 关闭保存后自动重跑。

固定的是直接依赖；当前已有环境的版本匹配和 `pip check` 已通过，尚未验证从空环境联网重装，也未验证 Linux。运行旧版 LangChain 0.3 工具调用实现时请使用此版本文件，不直接升级至其他大版本。

## 五分钟体验

1. **数据导入**：点击“加载模拟样例（CNY）”，自动应用映射。应看到 10 条有效记录、0 条排除、0 条重复。这些数据均为模拟订单。
2. **经营概览**：当前分析周期选 2026-09-08 至 2026-09-09；对比分析周期选 2026-09-01 至 2026-09-02。日期选择器要选完起止两个日期。应看到当前净销售额 44.90 CNY、对比净销售额 88.70 CNY。
3. **经营报告**：点击“生成基础经营周报”，核对变化 -43.80 CNY、3 个商品、5 条重点商品订单证据。下载 ZIP 并解压，可同时查看 Markdown、表格和 PNG。
4. **分析助手**：无密钥时暂不调用模型。有密钥后在左侧“模型设置”展开，选择 DeepSeek、模型 `deepseek-chat`，输入 API Key，再提问。

导入、概览和基础报告均无需密钥。ZIP 中是完整诊断结果；页面商品表默认只显示前 10 名，订单证据显示前 200 条。详细数字见 [报告示例](report-example.md)。

## 自有数据格式

输入必须是订单明细，一行一条明细；不是支付平台账单，也不是已经汇总的日报。支持 `.csv` 和 `.xlsx`；旧 `.xls` 需要先另存为 XLSX。XLSX 只读取第一张工作表。

| 标准字段 | 中文示例 | 要求 |
| --- | --- | --- |
| order_id | 订单编号 | 必填；字符串；同一订单可以有多条商品明细 |
| quantity | 数量 | 必填；有限数字；负数表示冲销，可有有效小数 |
| unit_price | 单价 | 必填；非负，最多两位有效小数；不能带货币符号或千分位逗号 |
| order_time | 日期 | 必填；建议 `2026-09-01 23:59:59`，不带时区 |
| product_id | 商品编号 | 与商品名称至少映射一个，才能分析商品贡献 |
| product_name | 商品名称 | 编号优先聚合；同名不同编号保持独立 |
| customer_id | 客户编号 | 可选；缺少时客户数无法统计 |
| country | 地区 | 可选；原样用于明细展示 |

页面尝试自动识别中英文列名，也可手动选择源列。必须选择真实币种并点击“应用电商字段映射”；选币种不会换汇。模拟样例是 CNY，UCI Online Retail 应选 GBP。

CSV 使用 UTF-8、UTF-8 BOM 或 GB18030。订单号和商品号按文本读取，保留 `0001`。XLSX 的编号列请在填写数据前设为文本；已经以数字保存、丢失的前导零或长编号精度无法恢复。导出的 CSV 在 Excel 中也应按文本导入编号列。

计算先校验日期、订单号、数量和金额；负单价、非有限数值、无法精确到最小货币单位的单价或明细金额会排除。比如 `0.125 × 8.00 = 1.00` 有效，`0.5 × 0.01 = 0.005` 无法精确到分而被排除。重复明细只提示、保留计算，用户需要先核实是否真是重复采集。

更换文件内容或重新应用映射会清空旧回答、分析条件和报告。相同内容的文件不会因普通页面交互而重复读取。有效数据仅保存在当前 Streamlit 会话，重启服务后需要重新导入。

## 连续对话与配置

没有明确日期的问题使用经营概览中的日期；明确日期优先。可依次尝试：

1. “分析本期经营情况”。
2. “继续按商品分析”。
3. “查看该商品明细”。
4. “改为 2026-09-09，查看商品 id:SKU-001 的明细”。

“该商品”在贡献排名之后默认指第一名，结果应注明精确标识；要取消商品条件可说“查看全部商品明细”。工具详情包含实际名称、有效参数、结构化结果；规则来源包含真实原文。可以清空对话，也可以在失败后重试保留的问题。

侧栏 API Key 仅供当前会话使用；留空时读取进程启动环境变量。项目不自动读取 `.env`，也不会把页面密钥写入进程环境变量或仓库。只有调用模型时才检查配置。可选 AI 解读是单独附加文本，基础报告数字由固定代码生成。

如需运行命令行真实 API 检查，可在 **PowerShell 7** 当前窗口中设置密钥；输入会被遮挡。脚本仅发送仓库模拟数据，调用可能产生 API 费用：

```powershell
$env:DEEPSEEK_API_KEY = Read-Host 'DeepSeek API Key' -MaskInput
.\.venv\Scripts\python.exe scripts/verify_deepseek.py
Remove-Item Env:DEEPSEEK_API_KEY
```

`status=passed` 只代表该次单轮工具调用、44.90 CNY 数值和净销售额规则引用通过；不是所有业务问答的成功率。`skipped` 表示未配置密钥，真实 API 尚未验收；`failed` 表示需根据错误检查配置、网络或模型调用。本轮只得到 `skipped`。

## 故障与限制

| 情况 | 处理 |
| --- | --- |
| 上传 XLS 失败 | 另存为 XLSX，不要直接改扩展名 |
| 缺少字段／没有有效记录 | 检查映射，展开“数据质量详情”查看排除原因；币种和映射都要应用 |
| 日期只选了一端 | 补齐起止日期；修改当前周期会重新设置默认相邻对比周期 |
| 百分比为空／不适用 | 基期为零时不计算增长率；总变化为零时商品贡献比例不适用 |
| 缺少客户数／商品贡献 | 没有对应字段；不通过模型补造数据 |
| 模型超时或失败 | 查看已完成工具结果；核对密钥、模型名和网络，再重试原问题 |
| 端口占用 | 确认已有服务用途，或将 `--server.port` 改为其他空闲端口 |
| 更新后启用高级工具仍长时间加载 | 可能是后台服务仍保留旧模块；停止对应项目服务后重启。新版侧栏显示当前模型配置，高级工具输入在表单内，空输入时执行按钮仍可点击，启用开关只刷新该区域；健康接口返回 ok 不代表已加载最新代码 |
| Markdown 图片不显示 | 下载并解压 ZIP，保留 `charts/` 与 `report.md` 的相对位置 |
| 云端图表中文缺字 | 安装可用 CJK 字体；本轮尚未验证 Linux 字体 |

主模型单次超时 45 秒，最多重试 1 次；Agent 最多 6 轮，在轮次边界检查 120 秒预算，不是正在运行请求的硬中断。TF-IDF 只做词语相关性检索，固定查询样本通过不意味着理解所有语义。

订单金额为数量×单价；不含优惠、成本、费用、税等，不等同支付宝实际到账。不做因果判断、客户留存分析或自动币种转换。排除记录摘要为整个文件，不能可靠按分析周期分配；重点商品证据也不是全部订单。

“高级工具”默认关闭，会执行模型生成的 Python，不能视为安全沙箱。修改数据的结果要下载并重新导入后才进入经营指标。尚未验证大数据性能、云端部署、真实模型质量及浏览器实际渲染；自动测试和 HTTP 服务检查不能代替这些验收。
