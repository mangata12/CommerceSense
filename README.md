# CommerceSense

基于 DataSense 二次开发的电商经营分析 Agent。

第一版目标：

- 上传订单明细并完成经营指标问答；
- 对比两个时间周期，分析商品对销售变化的贡献；
- 使用 LangChain Agent 编排业务分析工具；
- 使用 RAG 检索指标口径，并在回答中给出依据；
- 导出带数据依据的经营诊断周报。
